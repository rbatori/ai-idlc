# Code of Conduct

AI-IDLC is an open community project. Participation should be professional, constructive and respectful.

## Expected behavior

Contributors are expected to:

- discuss ideas and technical disagreements respectfully;
- criticize proposals, not people;
- provide context and evidence for claims where practical;
- welcome contributors with different levels of experience;
- avoid harassment, discrimination, threats and personal attacks;
- respect privacy, confidentiality and intellectual property;
- avoid publishing secrets, credentials or customer-confidential information.

## Scope

This code applies to repository issues, pull requests, discussions and other project spaces maintained for AI-IDLC.

## Enforcement

Maintainers may edit, remove or reject content and may restrict participation when behavior materially harms the community or project.

Concerns should be reported privately to the repository maintainer when public discussion would be inappropriate.
