# Governance Gates

AI-IDLC uses lightweight gates to make decisions explicit without forcing every initiative through the same amount of process.

| Gate | Decision |
|---|---|
| G0 | Intent accepted for analysis |
| G1 | Ready for Integration Design |
| G2 | Ready for Construction & Configuration |
| G3 | Ready for Validation |
| G4 | Ready for Delivery |
| G5 | Operational Acceptance |
| G6 | Intent Closed / Learning Captured |

## Tailoring

Gates are proportional to risk, scope and reversibility.

Low-risk read-only discovery may pass through simplified gates. High-impact identity, security, authorization, production or tenant-wide changes should require explicit human review.

## Minimum gate evidence

A gate decision should record:

- decision;
- date;
- reviewer or accountable role;
- unresolved risks;
- exceptions;
- evidence or references supporting the decision.
