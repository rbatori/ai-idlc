# $ai-idlc-capability-analysis

Match the active Intent to verified existing capabilities.

Load `.agents/ai-idlc/agents/capability-agent.md` as the lead persona.

## Workflow

1. Read the Intent and Discovery Record.
2. Decompose the desired outcome into required capabilities.
3. For each capability, evaluate ADOPT, CONFIGURE, INTEGRATE, AUTOMATE, EXTEND, then BUILD.
4. Create a Capability Matrix with evidence, gaps, constraints, strategy, and rationale.
5. Treat BUILD as an exception requiring explicit justification.
6. Record unresolved capability questions for Discovery rather than guessing.
7. Update workflow state when analysis is complete.
